# Milestones

*[Leia em português](MARCOS.md)*

One milestone at a time; each one ends with the owner seeing the result.

## M1 — Go core and Win95 window (done)

Done when: `wails build` produces the `.exe`; the window opens with the Win95 look; the org chart shows and edits
the agents of `tao.json`; the wizard creates a new agent; the Clients tab detects Claude Code, Codex and OpenCode;
the Console runs a real agent and shows its live output; the Tokens tab adds up the sessions; `go test ./...` passes.

| Package | Owner in M1 |
|---|---|
| `internal/failure` | Codex |
| `internal/store` | Codex |
| `internal/clients` | OpenCode |
| `internal/stream`, `internal/runner`, `internal/team`, `app.go`, `frontend/` | Claude Code |

## M2 — Tasks, sprints and the Agent Desk (done)

Done when: sprints are created, started and closed with a retro, carrying open tasks over; tasks are created by
hand or generated by an agent (arriving as proposals); each task runs on its assignee, goes to review on an agent
of another client and ends approved or comes back with changes; an agent's final question blocks the task and
shows up on the Desk, where Reply, Delegate and Archive act on it; step state lives in `.tao/state/`.

| Package | Owner in M2 |
|---|---|
| `internal/tasks` | Codex |
| `internal/fsx`, `app_tasks.go`, Sprints/Desk/task screens, runner fixes | Claude Code |

## M3 — Git flow and resilience (done)

Done when: each task runs on its own branch in `.tao/worktrees/<id>`; the work becomes a commit, the branch is
pushed and the PR opened with `gh` (or the merge is local, without GitHub); approval leaves the task waiting for
the merge, done with a button; a model out of quota switches by itself to another model of the client or to the
reserve agent (with automatic switching on), and the clocks show in Tools → Models and quotas; the reviewer is
always on a client other than whoever did the work; File → Import cards brings the roles and cards of
JinChronicles; the interface runs on Wails v3.

| Package | Owner in M3 |
|---|---|
| `internal/gitflow` | Codex |
| `internal/importer`, git fields and merge in `internal/tasks` | Codex |
| `app_git.go`, `app_models.go`, Wails v3 migration, screens, `docs/index.html` | Claude Code |

## M4 — Distribution and internationalization (in progress)

**Internationalization (done):** the whole system in English by default and Brazilian Portuguese as an option
(Tools → Language): interface, backend messages and errors, task history (stored as key + args, so it changes
language too), prompts sent to the agents, reviewer verdict in both languages, README and documents in English
with a Portuguese version, and a bilingual GitHub Pages site. Catalogs in `internal/i18n/locales/` and
`frontend/src/i18n/`, with a test that both languages have the same keys and placeholders.

**Next:** install and update clients through npm from the Clients tab, self-repair, NSIS installer,
Linux and macOS builds.

| Package | Owner in M4 (i18n) |
|---|---|
| `internal/*` translated, history with keys | Codex |
| `frontend/` translated, language switch in the interface | Codex |
| `internal/i18n`, app layer, prompts, documents, Pages | Claude Code |
